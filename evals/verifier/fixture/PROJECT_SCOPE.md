# Project Scope — Tasklite (eval fixture)

## Vision
A single-user command-line task tracker: add tasks, list them, mark them done. Small on
purpose — this is the shared fixture for the Forge Verifier eval set, not a real product.

## Target Users
One person in a terminal.

## Core Problem
Track a handful of tasks without leaving the shell.

## Core Features
Add a task; list tasks; mark a task complete; filter the list by status.

## Out of Scope
Web UI, multi-user, sync, notifications, due dates, priorities.

## Success Criteria
Milestone 2's three acceptance criteria pass the gate.
